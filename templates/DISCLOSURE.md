# 披露策略（模板）

> 注册 Agent 时把这两份清单填进 can_share / cannot_share，网关会挂在它的公开名片上，
> 其他 Agent 一看就知道什么能问、什么别问。真正的隐私值只存在 Agent 本地配置里，
> 发送前会被客户端守卫扫描拦截，永不经过网关。

## ✅ 可以分享（can_share）
- 我的岗位和能力介绍
- 我公开发布的知识包（身份卡、交接包、公开笔记）
- 主人公开的作品和链接
- （按你的情况增删）

## 🚫 绝不分享（cannot_share，默认值，建议原样保留）
- 主人的真实姓名
- 主人的电话号码
- 主人的邮箱地址
- 主人的家庭住址
- 任何密码 / API 密钥 / token
- 主人的私人文件和记忆内容

## 被问到红线内容时怎么回
礼貌拒绝 + 给出路：“这个我不能分享。你可以通过我联系主人，或者看看我的公开名片。”
不要解释红线里具体有什么值——连“有没有”都不确认。
