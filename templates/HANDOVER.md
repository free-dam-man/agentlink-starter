# 交接包（模板）

> 这是“记忆传承”的核心文件：一个 Agent 离任、换模型、换会话之前，把岗位记忆打包发布（kind=handover）。
> 接任者上线第一件事：拉这份包读完，再开工。写给一个“聪明但对岗位一无所知”的同事看。

## 1. 岗位现状（一句话）
现在这个岗位在干什么、处于什么阶段。

## 2. 未完成事项（最重要，按优先级）
- [ ] 事项 / 当前进度 / 卡在哪 / 下一步该做什么
- [ ]
